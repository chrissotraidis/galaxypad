# Preview 4 — mobile controls

Build **7168** for iPhone and iPad. This experimental controls update retains
Preview 3's runtime and compatible WBFS importer. It does not claim a performance
improvement. The macOS Preview 1 is unchanged.

## New controls

- **Controls → Gyro Cursor → This Device / Controller**: optional motion aiming
  for the Star Pointer. Defaults to Off; source and response settings persist.
  Controller motion requires a motion profile exposed by iOS/iPadOS.
- Response options: **0.5× / 1× / 1.5×**, vertical inversion and recenter.
  Click the right stick to recenter, or use the menu. Held touch overrides aim;
  releasing resumes from that position. The right stick also adjusts gyro aim.
- **Controls → Stick Mode → Ray Surfing**: left stick or touch movement stick
  steers the ray. Hold A to accelerate; Spin triggers the jump.
- **Controls → Stick Mode → Star Ball**: left stick or touch movement stick
  controls tilt with the upright remote pose. A jumps. Neutral stick centers
  tilt; it does not instantly remove the ball's momentum.

Select **Normal** again after each ride. Mode switching is manual and lasts for
that app session. Gyro cursor pauses during ride modes; gyro-based ride steering
and automatic ride detection are not implemented. These modes also cover ball
sections within mixed missions, not just the four commonly reported galaxies.

See [gyro details](GYRO-CURSOR.md) and [ride mappings](RIDE-CONTROLS.md).

## Install and preserve data

Download the IPA from [Preview 4](https://github.com/chrissotraidis/galaxypad/releases/tag/v0.1.0-preview.4)
and sign it with your own account. Keep the same bundle ID and signing identity
as your existing install and update in place. Back up saves/settings first;
do not uninstall to update. See [iPad installation](INSTALL_IPAD.md).
The package includes the generated AOT module, but no game image, extracted game
assets or saves. Supply the supported **USA RMGE01 revision 0** game image.

## Validation and limitations

The input math, mixed-source routing, saved settings, sensor lifetime and real
UIKit menu actions are covered by automated checks. Simulator sensor samples
are synthetic. Physical gyro response, controller-specific motion availability,
and completing the affected ray/ball missions still need player validation.
Performance, audio chopping in demanding scenes, and full-game compatibility
remain experimental. No new FPS gain is claimed.

All native host sources are rebuilt for this release. The tested Preview 3 core
archive and generated module are retained. Release assets include source
snapshots, build records, hashes and third-party notices. Historical core/module
provenance gaps remain documented; this is not a claim of complete clean-clone
or byte-identical reproducibility. See the bundled corresponding-source notice.
