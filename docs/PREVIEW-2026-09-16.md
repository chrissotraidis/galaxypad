# GalaxyPad Preview 3 — iPhone/iPad build 7166

Experimental refinement release based on the exact private build 7166 tested by
the owner on iPad Pro and iPhone 14. The owner reports it is working great on the
iPad. This is focused owner-reported acceptance, not full-game certification or
a matched performance comparison. The macOS Preview 1 is unchanged.

## Changes since Preview 2 / build 15

- Accept compatible bounded single-disc WBFS layouts containing the supported USA
  RMGE01 revision-0 executable content, instead of one exact container hash/size.
  Other revisions/regions, ISO and split/multidisc WBFS remain unsupported.
- Remove the duplicate touch Pause control and retain one Plus button with its
  existing layout identity and input behavior.
- Restore missing Game Mode opt-in/category metadata in the actual installed
  package. Staging and packaging now validate these keys. Game Mode is confirmed
  active by the iPhone owner; a meaningful FPS benefit is not established.
- Batch audio searches and cache sample-energy calculations to reduce processing
  work. Differential output/accounting checks pass. Component benchmarks are not
  whole-game FPS results.
- Include the tested low-speed audio-buffer handling repair. It addresses one
  reproduced starvation condition, but does not resolve all reported iPhone
  audio chopping under heavy gameplay.
- Retain experimental void/tail dispatch and indexed vertex batching from the
  tested app. These have correctness/component evidence, not a proven overall
  heavy-scene FPS gain. The source defaults remain opt-in.
- Correct Simulator configuration overrides and extend regression/packaging checks.

## Installation and limits

Download the IPA from [Preview 3](https://github.com/chrissotraidis/galaxypad/releases/tag/v0.1.0-preview.3).
It requires recipient signing of the app and nested module. Preserve the same
bundle/signing identity and back up saves before an in-place update; do not
uninstall first. No game image, extracted retail assets, saves or personal
provisioning is included. Supply your own supported game image.

The iPad installation preserved all 33 backed-up save/config/preference files;
the iPhone update preserved 54. The iPad retained 2x rendering. The owner then
reported the app working great. The release IPA is a signing-neutral repackaging
of that app, with added notices and stripped debug/signature metadata, and has
not separately received a recipient-signed installation test.

iPhone 14 demanding-scene slowdown and audio chopping remain known limitations.
Finger-to-cursor accuracy, broader device coverage and full-game validation remain
open. There is no claim of sustained 60 FPS on iPhone 14 or a quantified gameplay
speedup. Configured iOS/iPadOS 16+ is not an every-device compatibility guarantee.

## Source and package identity

Host source was compiled for 7163 from app checkpoint 9736708; 7164/7165 replaced
one mixer object using the maintained audio changes. 7166 restores packaged Game
Mode metadata and changes the build number. The generated module is retained
from 7162, with void dispatch. This is an incremental tested artifact, not a new
full rebuild of the latest source tree.

The release tag records app source and full recursive dependency pins. Release
assets include signing-neutral IPA, per-file manifest, checksums, maintained
source snapshots and a source/build-record supplement. The supplement identifies
recorded compilation inputs, hashes, SDK/compiler and experiment flags. Historical
runtime/module input gaps and private PGO/game inputs mean complete clean-clone,
byte-identical reproduction is not established. A current source snapshot does
not retroactively establish every historical compiled input.
