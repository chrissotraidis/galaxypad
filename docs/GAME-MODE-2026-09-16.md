# Game Mode investigation and build 7166

> Session closed: [current build, owner assessment and research handoff](SESSION-CLOSE-2026-09-16.md).
> This document retains the evidence and acceptance limits of its dated experiment.


The owner asked whether iOS Game Mode could be enabled or detected. The source
Info.plist already opted in, but the actual 7165 package did not contain
LSSupportsGameMode, GCSupportsGameMode or LSApplicationCategoryType. Incremental
7163–7165 builds copied an older packaged plist and changed only the build number.
This is a packaging defect; source-level declarations did not prove the installed
artifact included them. It does not prove iOS could never classify the old app
heuristically or establish that Game Mode caused the performance problems.

## Apple-supported behavior

[Apple WWDC25](https://developer.apple.com/videos/play/wwdc2025/209/)
identifies LSSupportsGameMode=true as the opt-in. The earlier
[WWDC24 guidance](https://developer.apple.com/videos/play/wwdc2024/10089/)
uses GCSupportsGameMode=true. Both are present in our source template and are
restored in 7166 alongside the adventure-game application category.

[Apple Support](https://support.apple.com/en-us/105118) says Game Mode gives games
priority over background work and improves Bluetooth accessory latency. It is
available on iPhone with iOS 18 or later. Full-screen games can activate it, but
an opt-in is not a guarantee of current system state or a demonstrated FPS gain.
Manually disabling it is remembered for that game until the user enables it again.
On this iOS 26 phone: open Control Center, tap GalaxyPad Game Overlay, tap Controls,
and inspect/toggle Game Mode. Gaming Focus is a separate feature.

No documented public force-on or active-state query API was found in the Apple
material or the installed iPhoneOS 26.5 public framework headers. Do not add an
in-app indicator that calls the plist Boolean the active state. The public keys
express eligibility. Private GamePolicy interfaces are not used by the app.

## Repair and prevention

Build 7166 copies the verified 7165 app and changes exactly the build number and
three missing keys. No host code, game module, audio setting or graphics setting
was changed. Executable hashes were identical before re-signing; signing then
updates the package seal. Same signer/entitlements/profile and deep strict
signature checks passed. The installed app reads back as 7166 and launches PID
4611. All 54 save/configuration/preference files were byte-identical after the
in-place update, before launch. The iPad was untouched.

`scripts/check-ios-game-mode.py` validates packaged plist keys and their types.
Private staging and iOS preview packaging invoke it. The focused regression
checks valid input, missing keys, disabled flags and incorrect plist types. The
actual 7165 plist fails and actual 7166 plist passes. The complete default
repository suite passed after these packaging changes. Source checks alone are not
a substitute for invoking this validator on any future incremental app package.

Private evidence: generated/game-mode-7166-20260916/ contains the metadata-only
receipt, signed app, signature verification, preservation hashes, installed-app
readback, startup console and repository-check.log. The earlier 7165 artifact
is preserved. This is a local test installation, not a release.

## Activation and performance acceptance

External device GamePolicy logging was attempted. An earlier activation in that
log belongs to a different game's foreground session; it is not GalaxyPad proof.
The available log does not establish the active state for the 7166 launch.
The owner subsequently confirmed Game Mode is enabled. They report at most a
slight, uncertain improvement, with substantial drops as scene activity increases.
Activation is owner-confirmed; a meaningful performance benefit is not established.
Game Mode does not close physical performance acceptance.

The owner has already rejected the preceding 7165 audio quality and reported no
perceptible gameplay-speed gain. The metadata fix does not reverse that result.
