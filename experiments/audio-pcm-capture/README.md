# Isolated post-mix PCM diagnostic

This is a temporary Simulator QA source, not a production audio change. `DiagnosticPcmCapture.h` and `CoreAudioSoundStream.cpp.patch` capture only GalaxyPad Mixer output: 48000 Hz, stereo, interleaved signed 16-bit little-endian samples, before RemoteIO output volume. It does not capture microphones, other apps, hardware output, or OS route processing.

Set `GALAXYPAD_AUDIO_PCM_PATH` to a new writable absolute `.wav` path inside the app container when launching the diagnostic app. Leave the variable unset to disable capture. The buffer stores the first 120 seconds of rendered frames, including startup and navigation. It allocates and touches 23,040,000 bytes during initialization; the callback only copies PCM and updates bounded accounting. It does not queue audio or change playback latency. It has no file I/O, allocation, locks, or new worker in the callback. Short/invalid callbacks and frames omitted after capacity remain explicit in the manifest. One serial RemoteIO callback producer and one stream owner are required; a simultaneous second stream declines capture.

Use **Stop Game** to destroy the sound stream and flush after RemoteIO stops and uninitializes. Pausing does not flush; wall-clock pause gaps are not synthesized. Force termination loses the recording. Output creation is exclusive, preserving earlier files. The companion `.wav.json` records format, frame counts, actual callback bounds, host timestamp ticks, and write success. A full-capacity buffer is written only at normal destruction, not immediately when it fills.

The build script `scripts/build-audio-pcm-diagnostic.py` uses the copied source in `generated/experiments/audio-pcm-capture-20260912`, frozen v8 headers via VFS, and a private aggregate. It replaces exactly CoreAudioSoundStream.cpp.o and verifies every other archive member, all host objects, old module and baseline executable remain byte-identical. No canonical source, app installation, or Simulator operation is performed. The copied source can be recreated by applying the included patch to its matching canonical source.

Built artifact: `generated/build/ios-simulator-audio-pcm-diagnostic-retry-20260912/GalaxyPad.app`; executable SHA-256 `6315f77597ea2cbcc32b9c5990dfc395a840d0477450cfeadd13967f5f82b847`. See its `manifest.json` for full provenance. The earlier build directory is an unsigned linked attempt whose audit failed on a non-UTF8 link-map symbol; it is preserved and not the selected diagnostic artifact.

`python3 tests/test-audio-pcm-capture.py` passes O3 and ASan/UBSan: exact stereo PCM/WAV roundtrip, capacity clipping and omitted frames, short/null callbacks, unsupported-rate rejection, and refusal to overwrite files. This instrumented app is for PCM QA only, not FPS acceptance. Building it does not establish that real-game PCM was captured or listened to.
