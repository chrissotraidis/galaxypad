# GalaxyPad branding provenance

Authored with the built-in image-generation tool on 2026-09-09 for GalaxyPad.
No reference images, Nintendo artwork, screenshots, extracted textures or game
assets were supplied. The retained original raster and exact prompt are documented
in [README](README.md). This is original project branding, not a copied game logo.

Mobile catalog: opaque1024px derivative of galaxypad-icon-source.png.
macOS: scripts/build-macos-icon.sh mechanically resizes that same original into
16/32/128/256/512pt slots at1×/2× and compiles an ICNS using Apple's iconutil.
Outputs remain in ignored generated/branding until included in a private package.

The PNG is not a layered/vector editable source. That original PRD requirement,
masked home-screen/Dock visual acceptance, and release approval remain open.
